# RandomWars 기획서

> 버전 0.1 (2026-09-28) · 기반: 예전 1.5.2 랜덤무기전쟁 서버 규칙
> 상태: 확정 (2026-09-28, 보급 방식과 무기 사용 제한 결정 반영)

## 1. 한 줄 소개

로비에서 플레이존으로 뛰어들면 맵의 랜덤한 곳에 떨어지고, 랜덤상자에서 나온 무기 조합으로 살아남는 서바이벌 PvP. 죽지 않는 한 계속 싸우고, 죽으면 모든 것을 잃는다.

## 2. 플랫폼과 제약

| 항목 | 내용 |
|---|---|
| 서버 | Paper 1.21.11 (Java 21) |
| 클라이언트 | 바닐라 1.21.11. 모드 설치 없음 |
| 커스텀 연출 | 서버 리소스팩 (Blockbench 모델 → `item_model` 컴포넌트, Display 엔티티) |
| 플러그인 | Kotlin + Gradle (IntelliJ), 단일 플러그인 `RandomWars` 안에 기능 모듈을 나눈다 |
| 저장소 | GitHub `RandomWars`, 작업 브랜치 `develop` |

## 3. 게임 흐름

```
[로비] ──입장──▶ [랜덤 워프] ──▶ [플레이존: 파밍·전투·보급] ──사망──▶ 아이템 전부 소멸 ──▶ [로비]
   ▲                                   │
   └──── /로비 (비전투 상태, 5초 대기) ───┘  (소지품 유지, 재입장 시 상자 재지급 없음)
```

### 3.1 공간 구성
- **로비**: 안전 지대. PvP 불가. 입장 포탈(또는 NPC/명령어 `/입장`)이 있다.
- **플레이존**: 실제 전장 맵. 월드 하나를 통째로 쓴다(기본값). 곳곳에 **지역명 장소**와 **엔더상자**가 배치된다.

## 4. 규칙 상세

### 규칙 1. 플레이존 입장 시 랜덤상자 2개
- 로비에서 플레이존으로 입장하면 일반 랜덤상자 2개를 받는다.
- 지급은 **한 목숨당 1회**. 사망 후 다시 입장하면 또 받는다. 살아서 로비에 다녀온 경우에는 다시 받지 않는다(무한 파밍 방지).

### 규칙 2. 처치 시 랜덤상자 1개
- 플레이어를 죽인 사람(마지막 타격자, 없으면 10초 내 최근 공격자)이 일반 랜덤상자 1개를 받는다.
- 어뷰징 방지 기본값: 같은 상대를 5분 안에 다시 처치하면 보상 없음.

### 규칙 3. 엔더상자와 전투 상태
- 맵 곳곳의 엔더상자로 랜덤상자·무기를 보관할 수 있다. 바닐라 엔더상자(플레이어별 27칸 개인 창고)를 그대로 쓰므로 **죽어도 엔더상자 안의 물건은 남는다**.
- **전투 상태**: 다른 플레이어에게 피해를 주거나 받으면 15초간 전투 상태(기본값). 공격이 이어지면 타이머가 갱신된다.
- 전투 상태에서는 엔더상자를 열 수 없고, `/로비`도 쓸 수 없다. 액션바에 남은 시간을 표시한다.
- 전투 상태에서 접속을 끊으면(전투 로그아웃) 사망 처리하고, 마지막 공격자가 처치 보상을 받는다.

### 규칙 4. 보급품 (10분 주기)
- 맵에는 이름 있는 지역(예: "폐허 성당", "북쪽 항구")이 설정 파일로 등록된다.
- 10분마다 보급이 열린다. **지역 중 2곳을 무작위로 골라 보급 상자 블록을 생성**하고 전체 공지(채팅·타이틀·보스바에 좌표 방향)를 띄운다. 먼저 여는 사람이 **보급 랜덤상자**(상위 등급 확률이 높은 상자) 1개를 얻는다. 다음 보급 때 안 열린 상자는 사라진다.
- 보급 상자는 전투 중에도 열 수 있다(보급지에서 교전을 유도).

### 규칙 5. 사망 시 100% 소멸
- 사망하면 인벤토리·갑옷·경험치가 드롭 없이 모두 사라진다(랜덤상자 포함).
- 부활 위치는 로비.

### 규칙 6. 대장전 방식
- 라운드나 제한 시간이 없다. 서버에 들어와 있는 동안 죽지 않으면 계속 플레이한다.
- 연속 처치(킬스트릭) 3/5/10에 전체 공지. 현재 최다 킬스트릭 보유자를 탭리스트/스코어보드에 표시(MVP 이후).

### 규칙 7. 랜덤 워프
- 입장 시 플레이존의 랜덤 좌표로 이동한다.
- 안전 조건: 단단한 블록 위, 머리 위 2칸 공기, 용암·물 아님, 다른 플레이어와 30블록 이상 떨어짐. 실패 시 미리 등록한 스폰 후보 지점 중 하나로 대체.
- 입장 직후 3초 무적(워프 킬 방지).

### 규칙 8. 무기 100종 이상, 카운터픽·연계픽

## 5. 무기 시스템

### 5.1 기본 구조
- 무기 = **바닐라 아이템 + 리소스팩 모델(`item_model`) + 스킬**.
- 모든 무기는 PDC(`randomwars:weapon_id`)로 식별한다. 이름이나 로어는 표시용일 뿐이다.
- 기본 공격은 바닐라 근접/원거리 공격, **우클릭 = 스킬**(쿨다운). 일부 무기는 웅크리기+우클릭 보조 스킬.
- 무기는 죽기 전까지 사라지지 않는다. 사용 횟수 제한은 없고 스킬은 **쿨다운만** 있다 (확정).

### 5.2 스킬은 부품으로 조립한다
100종을 하나하나 코딩하지 않는다. 재사용 가능한 **스킬 부품**(약 25~30개)을 Kotlin으로 만들고, 무기는 YAML에서 부품과 수치를 조합해 정의한다.

| 역할 태그 | 스킬 부품 예시 |
|---|---|
| 이동 | 돌진, 순간이동, **대상 등 뒤로 이동**, 도약, 갈고리 끌어당기기 |
| 폭딜 | **짧은 시간 연타**, 차징 강타, 출혈(도트), 처형(체력 낮은 대상 추가 피해) |
| 제어 | 기절(이동 불가), 둔화, 넉백, 끌어당기기, 침묵(스킬 봉인) |
| 원거리 | 투사체, 관통 광선, 범위 폭발, 유도탄 |
| 방어 | 보호막, 반사, 무적 회피, 은신 |
| 설치/지원 | 덫, 장벽, 회복 장판, 표식(받는 피해 증가) |

### 5.3 카운터픽과 연계픽
- 모든 무기에 역할 태그를 달고, 태그끼리의 상성표를 기준으로 밸런스를 잡는다.
- **연계 예시 (사용자 예시)**: `대상 등 뒤로 이동` → `짧은 시간 연타` = 뒤잡고 순삭.
- **카운터 예시**: 연타 폭딜 ↔ 보호막/반사, 순간이동 ↔ 둔화 장판/침묵, 원거리 ↔ 돌진, 은신 ↔ 범위 공격·표식.
- 상성은 "반드시 이긴다"가 아니라 "유리하다" 수준으로 둔다.

### 5.4 등급

|---|---|---|---|
| 일반 | 60% | 0% | 스킬 1개, 긴 쿨다운 |
| 희귀 | 28% | 40% | |

## 6. 랜덤상자

- 손에 들고 우클릭하면 1개 소모 후 1.5초 룰렛 연출(타이틀에 무기 이름이 빠르게 바뀌다 멈춤 + 사운드) 뒤 무기 1개를 받는다.
- 종류: **일반 랜덤상자**, **보급 랜덤상자**. 확률표는 설정 파일에서 조정한다.
- 설치(블록으로 놓기) 불가, 인벤토리가 가득 차면 열리지 않는다.
- 결과물은 무기 90%, 소모품(회복 물약, 황금사과, 폭죽 등) 10%(기본값).
- 전투 중에도 열 수 있다.

## 7. 리소스팩과 Blockbench

- Blockbench로 무기 모델(`.bbmodel`)을 만들고 Java 아이템 모델로 내보낸다.
- 1.21.4 이후 방식인 `item_model` 컴포넌트를 쓴다: `assets/randomwars/items/<무기>.json` → `assets/randomwars/models/item/<무기>.json`.
- 스킬 이펙트(칼날 궤적, 장판, 투사체 모양 등)는 `ItemDisplay` 엔티티에 모델을 씌우고 변환 보간으로 움직인다. 파티클·사운드를 곁들인다.
- 서버 접속 시 리소스팩을 필수로 받게 한다(`server.properties`의 `resource-pack`, `resource-pack-sha1`, `require-resource-pack`). 호스팅은 GitHub Releases(기본값).
